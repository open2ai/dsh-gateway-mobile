TROUBLESHOOTING

常见故障

按现象展开排查；多数问题与隧道、配对码或微信上下文有关

手机扫码后打不开页面 / 配对失败

先在「概览」顶部的状态 chips 确认公网隧道已连接。Quick Tunnel 重启后会更换域名，旧二维码立即失效，需要重新生成配对码并重新配对。若隧道正常仍打不开，用连接诊断检查 WebSocket 握手与 Cookie。

打开连接诊断
隧道未连接 / 公网地址为空

检查 cloudflared 是否安装（网关会尝试自动下载），或网络是否允许出站 443。可点「重启」隧道；Named Tunnel 模式还会检查本地 metrics 端口。找不到原因时运行 npm run doctor 做只读体检。

微信无 context / 收不到消息

微信「运行详情」里若上下文年龄持续为 -1 或最新 owner context 已超过 30 分钟，需要让 owner 再发一条消息；若出现「微信会话已过期」，重新扫码登录即可。无 owner 时先扫码并允许连接。

配对码过期

配对码默认 15 分钟有效。本页可见时若检测到配对码已失效，会自动重新生成一次；也可以到「配对」页点「重新生成」。有效期可在「设置 → 配对码与设备登录」调整。

轮换密钥后旧设备失效

轮换会更换会话签名与凭证加密的活动密钥。旧密文仍可解密，但部分已签发会话可能失效，手机需要重新配对。若手机大面积掉线，保留当前密钥并重新配对即可，无需再次轮换。
