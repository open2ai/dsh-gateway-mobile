# DSH 手机与微信网关

把本机 `dsh web` 通过 **Cloudflare Quick Tunnel** 安全地开放给手机；可选接入 **微信 ClawBot/iLink**，在微信里完成审批、回答提问、接收完成通知。DSH 本体始终只监听回环地址。

## 它解决什么问题

- 不在同一局域网、没有公网 IP 时，用手机继续 DSH 会话。
- 离开电脑后，审批和提问能在手机上处理，完成结果能推到微信。
- 不想把 DSH 的 Cookie 或端口直接暴露到公网。

## 主要能力

- **手机访问** — 管理后台生成一次性配对码，手机扫码后输入 8 位码完成配对；每台设备独立 HMAC 会话，支持滑动续期、重命名、撤销与自动过期。
- **微信通道** — 扫码登录 ClawBot/iLink；文本、图片双向桥接到专用 DSH 会话；默认只接受绑定微信账号的消息、审批与通知；审批回复 `Y`/`N`，`ask_user_question` 支持选项序号、选项文字、多选 `1,3`、自定义文字和“跳过”。
- **完成通知** — 跨会话推送，支持合并窗口、单会话冷却、全局间隔、每小时上限，均可在管理后台在线调整。
- **运维面板** — 隧道启停/重连与状态、微信运行状态与所有者、设备列表、日志、连接诊断、深度健康检查、审计导出、密钥轮换、帮助页、深色主题与中英界面。

## 使用前提

- DSH `0.2.2-rc.1`（`engines.dsh` 精确匹配）。
- cloudflared（未安装时会尝试自动下载）。
- 管理后台仅限本机：`http://127.0.0.1:3081/mobile/admin`。

## 安全模型

- DSH 不监听公网；公网入口由网关终止，并校验设备会话后才反向代理到 DSH。
- DSH 的浏览器 Cookie 保留在本机插件进程内，不下发到设备。
- 微信完整用户 ID 不持久化、不写日志；Bot token 加密保存；扫码登录只允许在环回管理后台确认。
- Quick Tunnel 是 Cloudflare 的测试/开发设施；长期使用建议 Named Tunnel 或自建反向代理。
