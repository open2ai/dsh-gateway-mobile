## 0.1.0 — 2026-10-23

First working implementation of the DSH Gateway Mobile plugin: a loopback gateway with Cloudflare Quick Tunnel, one-time device pairing, HMAC cookie sessions, and HTTP/WebSocket reverse proxying for DSH.

Ships the admin console and phone PWA pages (zh/en, dark/light) covering pairing, device revoke and permanent delete, logs, settings, OAuth binding and diagnostics, plus 45 automated tests and a real-DSH integration script.
